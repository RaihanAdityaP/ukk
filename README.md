# Wijaya Living & Elektronik

E-commerce sederhana berbasis Next.js + Supabase, dibuat untuk Pra-UKK PPLG 2026.

🔗 Demo: https://ukk-gamma.vercel.app/

## Tentang

Toko online dengan dua peran pengguna. **Customer** bisa lihat-lihat produk, kasih review & rating, tambah ke keranjang, sampai checkout. **Admin** bisa kelola produk (termasuk upload gambar asli) dan pantau pesanan masuk. Login/akun, cart, dan proteksi halaman berbasis role semuanya jalan lewat Supabase.

**Tech stack**: Next.js 15 + TypeScript + Tailwind CSS, dengan Supabase (Postgres, Auth, Storage) sebagai backend.
